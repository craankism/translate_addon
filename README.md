# LinkClipboard

A World of Warcraft addon that makes chat links and Russian messages easy to copy.

## Features

- Appends a **[Copy]** button next to URLs in chat messages — clicking opens a dialog with the link pre-selected for copying
- **[Discord]** button for `discord.gg` / `discord.com` links
- **[Softres]** button for `softres.it` links
- **[Copy]** button next to messages containing Cyrillic characters, for easy translation

## Installation

1. Download or clone this repository
2. Place the `LinkClipboard` folder inside your WoW addons directory:
   ```
   World of Warcraft/_retail_/Interface/AddOns/LinkClipboard
   ```
3. Restart WoW or reload your UI (`/reload`)

## Usage

- Any URL or Cyrillic message in chat will automatically get a clickable button
- Click the button to open the copy dialog
- The text is auto-selected — press `Ctrl+C` to copy, or `Esc` to close

## Compatibility

- WoW Interface version: 11.0.2
